## Compatibility closure

The 1.6 release retains:

1. the stable `1.0.0` compatibility floor;
2. unchanged public signatures from 1.0–1.5;
3. unchanged documented wire bytes for existing public CSI operations;
4. one authoritative `TerminalSession` input reader;
5. bounded parser, response, query, and late-response ownership state;
6. timeout late-response ownership measured from the logical monotonic timeout deadline;
7. explicit cancellation/suspend/disposal ownership measured from the actual interruption point;
8. TermInfo authority for exact selected-terminal recipes;
9. no terminal-brand capability oracle;
10. no conversion of query timeout into unsupported truth;
11. no generic raw public CSI writer;
12. no premature public geometry, Sixel, or Kitty Graphics surface.
