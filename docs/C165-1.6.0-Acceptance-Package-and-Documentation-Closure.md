## Public API closure

Version 1.6 intentionally adds no public API.

C160–C164 add internal grammar, semantic parsing, consolidation, geometry, and hardening infrastructure only. Therefore the frozen public surface remains the same surface carried by 1.5 from the 1.4 machine baseline.

C165 does not create a duplicate `Public-API-Baseline-1.6` file for an unchanged API. The package-candidate gate continues to generate and compare the net8.0, net9.0, and net10.0 surfaces and enforce the existing stable baseline.

## Compatibility closure

The 1.6 release retains:

1. the stable `1.0.0` compatibility floor;
2. unchanged public signatures from 1.0–1.5;
3. unchanged documented wire bytes for existing public CSI operations;
4. one authoritative `TerminalSession` input reader;
5. bounded parser, response, query, and late-response ownership state;
6. TermInfo authority for exact selected-terminal recipes;
7. no terminal-brand capability oracle;
8. no conversion of query timeout into unsupported truth;
9. no generic raw public CSI writer;
10. no premature public Sixel or Kitty Graphics surface.
