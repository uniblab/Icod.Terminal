# Icod.Terminal 0.6.1 — Dependency Refresh

**Release:** `0.6.1`  
**Purpose:** maintenance update for the `Icod.TermInfo` dependency

## Scope

`Icod.Terminal 0.6.1` is a maintenance release over the stable 0.6 line.

The release changes the runtime dependency:

```text
Icod.TermInfo 1.4.1 -> 1.10.0
```

`Icod.Timing` remains at `1.0.0`.

No public `Icod.Terminal` API change is intended. The stable OSC 8 hyperlink,
query-routing, lifecycle, input, presentation, and package contracts from 0.6.0
remain unchanged.

## Versioning

The package metadata is:

```text
Version        0.6.1
PackageVersion 0.6.1
AssemblyVersion 0.6.0.0
```

The assembly version remains on the 0.6 compatibility line for this patch release.

## Package verification

The package verifier is updated to require `Icod.TermInfo 1.10.0` in every
`net8.0`, `net9.0`, and `net10.0` dependency group. The fresh package smoke
consumer documentation is updated to reflect the same dependency closure.

## Release gate

Before tagging `v0.6.1`:

1. pull-request Staging validation must pass;
2. the packed `Icod.Terminal 0.6.1` artifact must verify against the exact
   `Icod.TermInfo 1.10.0` dependency;
3. package-only consumers must restore and execute for all supported TFMs;
4. the PR must merge to `main`;
5. the normal `main` Release workflow must pass;
6. only then should `v0.6.1` be created for publication.
