# Icod.Terminal 1.24.1 Release Notes

**Status:** Patch package candidate in PR #70. Merge, GitHub release, and NuGet publication remain maintainer actions.

## Persistent Kitty verification

Version 1.24.1 no longer treats a successful generic Kitty Graphics query as proof that persistent raster resources are usable. `VerifyCapabilityAsync(TerminalCapability.PersistentRasterGraphics)` first establishes the Kitty dialect, then sends one bounded 1x1 RGB24 persistent direct upload with a private image number. Persistent support becomes verified only when the terminal returns a successful acknowledgement containing the correlated image number and a nonzero terminal-assigned image id.

The temporary resource is deleted before verification returns. If cleanup fails, the session does not record persistent support as verified. A zero or malformed terminal-assigned id records the persistent operation as unsupported; a missing acknowledgement leaves support unknown. Cancellation and transport failures retain their existing behavior.

This distinction is observable through the existing capability API: generic Kitty evidence can still verify `RasterGraphics`, but it leaves `PersistentRasterGraphics` unknown until the persistent identity exchange succeeds. No native platform call, terminal-brand allowlist, or shell-specific branch is added.

## Compatibility

This patch changes no public signature, enum value, target framework, registry ceiling, or ownership contract from 1.24.0. It continues to target `net8.0`, `net9.0`, and `net10.0`, with production dependencies `Icod.TermInfo 1.17.0` and `Icod.Timing 1.0.0`. The stable 1.0 compatibility floor and the 1.24 public API fingerprint remain unchanged.

Consumers should continue to call `VerifyCapabilityAsync(TerminalCapability.PersistentRasterGraphics)` before creating persistent raster resources. Terminals that answer generic Kitty queries but return an invalid persistent image identity now receive a controlled non-usable status, allowing higher-level libraries to select their text fallback.
