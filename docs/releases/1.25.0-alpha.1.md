# Icod.Terminal 1.25.0-alpha.1

This prerelease retains the complete-image screen transaction API introduced in
1.25.0-alpha and corrects relative cursor planning exposed by DCurses live testing.

## Cursor positioning

Relative cursor candidates containing carriage return or line feed are excluded.
An advertised `cud1=LF` is unsafe when output processing translates LF to CRLF:
the planner would otherwise assume the original column survived and later writes
could leave trails at the left margin. Safe advertised relative motion or absolute
addressing is used instead; when neither exists, planning returns unavailable.

The correction applies across platforms without native calls, terminal-name
heuristics, guessed control sequences, or changes to the terminfo database.
Explicit carriage-return positioning and application newline output remain available.

## Compatibility and verification

There are no public API or dependency changes from 1.25.0-alpha. The package still
targets .NET 8, 9 and 10. Regression coverage exercises parameterized and repeated
line-break capabilities, safe relative fallback, absolute fallback, and unavailable
motion with no output.

Graphics capability verification is unchanged. A text-only result in WezTerm does
not by itself establish an emulator-wide graphics limitation. Live DCurses testing
must be repeated after consuming this package; CI validates planning and protocol
output, not physical terminal rendering.

This is a new package version; it does not replace the published 1.25.0-alpha.
Merge, tag, and NuGet publication remain maintainer actions.
