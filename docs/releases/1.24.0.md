# Icod.Terminal 1.24.0 Release Notes

**Status:** Stable package candidate in PR #69. Merge, tag, GitHub release, and NuGet publication remain maintainer actions.

## Raster geometry and planning

Version 1.24 adds positive `TerminalPixelDimensions`, direct bounded terminal/cell pixel queries, and `TerminalPixelGeometry.TryDeriveCellDimensions(...)`. Exact derivation is a caller-selected fallback: both observations must be positive and each terminal-pixel axis must divide evenly by its current character axis. Terminal never rounds, guesses, caches the geometry, or treats timeout as unsupported. Re-query after resize.

`TerminalRasterResource.PixelWidth` and `PixelHeight` expose immutable intrinsic source geometry without I/O. `GetRasterPlanningSnapshot()` reports nine fixed library ceilings and advisory current local counts for resources, combined placements, and allocated animation frames including append reservations. It does not report terminal memory, reserve capacity, or guarantee a later allocation; create and append results remain authoritative.

## Focused operation evidence

`InspectRasterOperation(...)` describes current-generation support knowledge, endpoint availability, evidence lifetime, and usability for frame composition, RGB24 region replacement, or RGBA32 region replacement. Only a successful acknowledgement verifies the matching operation. Evidence for one operation does not verify another, and lifecycle generation advance clears it. Rejection, timeout, cancellation, transport loss, malformed response, or missing-resource invalidation does not fabricate unsupported evidence.

## Tile-atlas witness and ownership boundary

The raster-animation sample's `--tile-atlas` path uses only public 1.24 contracts, opaque placeholder cells, two known frames, acknowledged regional updates, and frame selection. It edits the unselected frame, awaits every result, selects only after all edits succeed, then swaps caller-owned front/back references. It measures 1, 4, 16, and 64 regions and selects an explicit text fallback when geometry, planning, placeholders, mutations, or selection are unavailable.

The witness demonstrates Terminal mechanics, not remote atomicity, gapless presentation, physical rendering, terminal storage capacity, or a complete renderer. `Icod.DCurses` or the application continues to own tiles, assets, retained cells, viewport, clipping, damage, overlays, refresh, and front/back policy. The game owns maps, actors, collision, visibility, scheduling, persistence, and rules.

## Compatibility, dependencies, and non-goals

Every 1.23 public signature and enum value remains available, and the stable 1.0 compatibility floor is unchanged. The package continues to target `net8.0`, `net9.0`, and `net10.0`; see the [compatibility and versioning policy](../Compatibility-and-Versioning.md). Production dependencies remain `Icod.TermInfo 1.17.0` and `Icod.Timing 1.0.0`; `Icod.TermInfo.Inspection` remains optional and outside the production graph.

Version 1.24 does not add tile maps, cameras, scene graphs, asset decoding, palette policy, collision, visibility, game scheduling, batch edits, Indexed8 partial updates, gapless frames, remote-capacity queries, hidden replay, or PTY/ConPTY hosting. A possible 1.25 batch/Indexed8 release remains gated on a real DCurses package workload showing material need; this synthetic Terminal witness alone does not open or promise it.
