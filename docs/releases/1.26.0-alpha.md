# Icod.Terminal 1.26.0-alpha Release Notes

**Status:** Prerelease for compatibility-sample review and live terminal qualification. Stable 1.26.0 metadata remains deferred until the matrix and exact candidate are accepted.

## Compatibility qualification

This prerelease adds a public-only executable compatibility sample, a bounded JSON evidence contract, deterministic versioned matrix generation, and fresh-package acceptance on .NET 8, 9, and 10. It adds no production public API.

The matrix covers established nongraphics behavior: identity and bounded queries; OSC 0/1/2 titles; OSC 7 location; OSC 8 hyperlinks; OSC 9, 777, and 99 notifications; OSC 9;4 progress; OSC 52 clipboard; OSC 133, 633, and reviewed 1337 metadata; rich input and lifecycle events; cursor style; synchronized output; pointer shape; and colors.

Every live side effect requires an in-session choice. Reports separate automated observations from operator-visible confirmation and exclude raw clipboard content, keystrokes, command lines, environment dumps, and arbitrary terminal replies. Timeout, permission denial, policy suppression, and ambiguity remain `Inconclusive`; absent evidence remains `NotRun`.

## Compatibility and migration

Existing 1.25 public signatures and enum values are unchanged. The stable 1.0 compatibility floor and `net8.0`, `net9.0`, and `net10.0` targets remain. Production dependencies remain `Icod.TermInfo 1.17.0` and `Icod.Timing 1.0.0`; this work requires no Icod.TermInfo change.

Applications do not need to migrate. The sample and evidence files are repository tooling, not new runtime behavior. Graphics qualification remains on hold and is outside this matrix.

## Validation and limitations

The package gate compiles the sample against a freshly produced package and runs every headless command on all three target frameworks. Interactive results require maintainer review and exact environment identity; ordinary CI cannot fabricate them.

At this alpha, no live evidence has been accepted into the 1.26 matrix. All ten primary lanes and the VS Code companion lane are therefore explicitly `NotRun`. Stable closure, cross-platform workflow identities, artifact hashes, and accepted live results remain pending.
