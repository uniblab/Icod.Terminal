# Icod.Terminal 1.6.0

`Icod.Terminal 1.6.0` is the complete-CSI grammar and consolidation release for the stable 1.x line.

It builds directly on the 1.5 control-language normalization. Version 1.6 establishes one bounded reusable CSI grammar, migrates existing CSI operations onto that shared foundation, adds the internal terminal/cell pixel-geometry observations needed by later raster backends, and hardens query routing against hostile fragmentation and oversized correlated responses.

## Complete CSI grammar

C160 introduces `TerminalCsiSyntax` above the normalized 1.5 structural frame representation. It retains the complete ECMA-style CSI structure without prematurely assigning dialect semantics:

```text
parameter bytes      0x30–0x3F
intermediate bytes   0x20–0x2F
final byte           0x40–0x7E
```

The grammar preserves:

- 7-bit and supported 8-bit CSI framing;
- leading private-use parameter bytes;
- semicolon-delimited parameters;
- colon-delimited subparameters;
- omitted and empty parameter/subparameter components;
- intermediate bytes and final selectors;
- original raw parameter bytes.

All parser state and cardinality remain bounded.

C161 adds typed numeric/component semantics while deliberately retaining the distinction between omitted, empty, zero, and explicit numeric values. Numeric conversion is overflow-safe and protocol parsers can require or forbid private prefixes, intermediates, empty parameters, and colon subparameters as their dialect contracts demand.

## Existing CSI consolidation

C162 moves existing CSI construction and response parsing onto the common grammar/writer path while retaining released wire bytes. The consolidated set includes:

- Primary and Secondary Device Attributes;
- Device Status Report;
- Cursor Position Report;
- DEC private-mode set/reset;
- synchronized-output mode 2026;
- Kitty progressive-keyboard query, push, and pop;
- Kitty keyboard query plus Primary-DA barrier;
- mouse tracking modes 1000, 1002, and 1003;
- SGR mouse encoding mode 1006;
- existing DECSCUSR cursor-style output through `CsiWriter`.

TermInfo remains authoritative where the selected terminal supplies exact recipes. Bracketed-paste and focus enable/disable strings are not reconstructed from assumed mode numbers, and mouse advertisement still depends on the reviewed TermInfo metadata before canonical tracking modes are emitted.

## Terminal and cell pixel geometry

C163 adds an internal geometry substrate for later Sixel and Kitty Graphics work without freezing a public geometry API prematurely.

The active query forms are:

```text
CSI 14 t  -> CSI 4 ; height ; width t   terminal pixels
CSI 16 t  -> CSI 6 ; height ; width t   cell pixels
```

The response matchers distinguish selector 4 from selector 6, support seven-bit and eight-bit CSI framing, require positive bounded dimensions, and execute through the existing `TerminalSession` query transaction manager so one live session remains the authoritative reader.

Cell-pixel dimensions may also be derived from character-grid and terminal-pixel observations only when both dimensions divide exactly; the implementation never rounds fractional geometry.

The POSIX native audit confirmed that `TIOCGWINSZ` already carries pixel width/height, but the current `ITerminalControlProvider.GetSize(...)` contract exposes only columns/rows. Version 1.6 deliberately does not expand that provider/public contract merely to surface optional native fields.

## CSI hardening and recovery

C164 qualifies the grammar and query path at resource boundaries and hostile fragmentation points:

- exact maximum raw parameter bytes;
- exact maximum parameter and subparameter counts;
- numeric maximum versus maximum-plus-one;
- mixed private bytes, semicolons, colons, and empty components;
- CAN/SUB invalidation;
- every read-chunk split point of a real geometry response through `TerminalSession`;
- malformed correlated geometry response followed by a successful later query;
- oversized correlated geometry response, bounded drain/resynchronization, and successful subsequent query;
- retained one-reader ownership throughout the fragmented and recovery cases.

C164 also hardens query timeout ownership. Late-response ownership after timeout is measured from the logical monotonic timeout deadline rather than from when a scheduler happens to run the timeout continuation. Cancellation and other explicit interruption paths retain their actual interruption-time semantics.

## Compatibility

Version 1.6 adds no public API. The stable 1.0–1.5 public surface remains unchanged, and no generic raw public CSI writer is introduced.

The package continues to target:

```text
net8.0
net9.0
net10.0
```

and retains the dependency floor:

```text
Icod.TermInfo 1.10.0
Icod.Timing   1.0.0
```

The 1.5/1.4 machine public-API baseline therefore remains authoritative rather than creating a duplicate 1.6 baseline for an identical surface.
