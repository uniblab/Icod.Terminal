# Icod.Terminal 1.6.0

`Icod.Terminal 1.6.0` is the CSI consolidation release for the stable 1.x line.

It builds directly on the 1.5 control-language normalization and focuses on one complete reusable CSI grammar, migration of existing CSI operations onto that grammar, and terminal/cell pixel geometry needed by later raster backends.

## Development program

```text
C160  complete CSI grammar foundation
C161  typed CSI parameter semantics
C162  existing CSI consolidation
C163  terminal/cell pixel geometry
C164  CSI hardening, fragmentation, and fuzz/property coverage
C165  acceptance/package/documentation closure
```

## C160 foundation

The first tranche introduces an internal syntax layer above the 1.5 structural frame representation.

It retains:

```text
parameter bytes      0x30–0x3F
intermediate bytes   0x20–0x2F
final byte           0x40–0x7E
```

and structurally preserves:

- 7-bit and 8-bit CSI framing;
- leading private-use parameter bytes;
- semicolon-delimited parameters;
- colon-delimited subparameters;
- empty parameter/subparameter components;
- intermediate bytes;
- the final byte;
- original raw parameter bytes.

C160 deliberately performs no generic numeric coercion. Whether omitted or empty components mean default, zero, inherited state, or invalid input is dialect-specific and belongs to later semantic parsing.

## Compatibility

Version 1.6 preserves the stable 1.x ownership and security architecture:

- one authoritative `TerminalSession` input reader;
- bounded parsing and query state;
- no generic raw public CSI writer;
- existing explicit wire APIs retain their released bytes;
- terminal identity is not treated as support proof;
- timeout is not automatically unsupported truth.

The package continues to target:

```text
net8.0
net9.0
net10.0
```

and retains the current dependency floor:

```text
Icod.TermInfo 1.10.0
Icod.Timing   1.0.0
```
