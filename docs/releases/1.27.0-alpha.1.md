# Icod.Terminal 1.27.0-alpha.1 Release Notes

**Status:** Development prerelease for the approved terminal appearance and in-band resize awareness work. Publication is not implied; merge, tag, GitHub release, and NuGet publication remain explicit maintainer actions.

## Environment-event contract

This alpha implements additive typed values for terminal-reported dark/light appearance and in-band text-area resize observations. It appends appearance and in-band resize kinds to the existing semantic-event family without renumbering notification events.

The payloads preserve provenance: in-band dimensions do not replace native resize lifecycle events, `GetSize()`, or `GetDimensions()`. Applications continue to own theme selection, layout, damage, and repaint policy.

Strict bounded protocol parsing, QueryAppearanceAsync, independent appearance/resize reporting leases, lifecycle-safe ownership, and fresh-package acceptance are implemented. The [1.27 API baseline](../Public-API-Baseline-1.27.md) freezes the additive surface across net8.0, net9.0 and net10.0. Reporting remains opt-in; explicit unavailable is distinct from exceptional negotiation. Native geometry remains separate and repeated observations are retained.

The remaining acceptance work is reviewed live-terminal evidence: a positive appearance query/report, initial and changed in-band resize, and a missing/unavailable lane with native input/resize intact. The [1.27 matrix](../compatibility/1.27.0.md) marks all live lanes NotRun until reviewed evidence is accepted. Stable promotion is gated on these witnesses.

## Compatibility

Existing 1.x public members and enum values remain unchanged. The package continues to target .NET 8, 9, and 10 on managed Windows, Linux, and macOS. Production dependencies remain `Icod.TermInfo 1.17.0` and `Icod.Timing 1.0.0`; this feature requires no Icod.TermInfo change.

Terminal branding, successful writes, and protocol documentation are not support evidence. Positive appearance and resize support will be recorded only after bounded tests on exact terminal, operating-system, and transport versions. Graphics development remains on hold.

See the [1.27 development roadmap](../../Icod.Terminal-1.27.0-Development-Roadmap.md), [approved design](../superpowers/specs/2026-10-05-terminal-appearance-resize-awareness-design.md), and [compatibility policy](../Compatibility-and-Versioning.md).
