# Icod.Terminal 1.27.0-alpha.1 Release Notes

**Status:** Development prerelease for the approved terminal appearance and in-band resize awareness work. Publication is not implied; merge, tag, GitHub release, and NuGet publication remain explicit maintainer actions.

## Environment-event contract

This first alpha establishes additive typed values for terminal-reported dark/light appearance and in-band text-area resize observations. It appends appearance and in-band resize kinds to the existing semantic-event family without renumbering notification events.

The payloads preserve provenance: in-band dimensions do not replace native resize lifecycle events, `GetSize()`, or `GetDimensions()`. Applications continue to own theme selection, layout, damage, and repaint policy.

The remaining 1.27 work will add strict protocol parsing, the bounded appearance query, independently acquired reporting modes, lifecycle-safe ownership, package acceptance, and reviewed live-terminal evidence.

## Compatibility

Existing 1.x public members and enum values remain unchanged. The package continues to target .NET 8, 9, and 10 on managed Windows, Linux, and macOS. Production dependencies remain `Icod.TermInfo 1.17.0` and `Icod.Timing 1.0.0`; this feature requires no Icod.TermInfo change.

Terminal branding, successful writes, and protocol documentation are not support evidence. Positive appearance and resize support will be recorded only after bounded tests on exact terminal, operating-system, and transport versions. Graphics development remains on hold.
