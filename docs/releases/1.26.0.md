# Icod.Terminal 1.26.0

Icod.Terminal 1.26.0 adds a versioned, evidence-backed compatibility
qualification workflow for the established nongraphics public surface. It adds no
production runtime API, preserves the stable 1.0.0 compatibility floor, and
retains every 1.25.0 public signature and enum value.

## Compatibility qualification

The release includes `Icod.Terminal.Compatibility.Sample`, a public-API-only
executable that can list and describe scenarios without opening a terminal, run
consented live scenarios, write bounded JSON evidence, and deterministically
render a versioned Markdown matrix.

The initial reviewed matrix records `Pass` for:

- `identity.session/v1` and `query.dimensions/v1` in Windows Terminal
  1.24.11911.0 on Windows Version 10.0.26200.9457; and
- the same two scenarios in Kitty 0.32.2 on Ubuntu 24.04 through WSL 2.6.1.0.

Each result qualifies only its exact terminal, operating system, optional
transport, source/package identity, and scenario revision. It does not promote
terminal branding, successful output, silence, or absent results into broader
support claims. All unrecorded scenarios and lanes remain explicitly
`NotRun`.

## Privacy and side effects

Reports contain bounded identity labels, scenario revision, outcome, observation
flags, and a bounded note. They exclude raw clipboard data, keystrokes, command
lines, environment dumps, arbitrary reply bytes, current working directories,
and implicit user or host identities.

Every external side effect requires an in-session choice before it occurs.
Permission denial, policy suppression, timeouts, and ambiguous behavior remain
`Inconclusive`; they are not treated as unsupported behavior.

## Compatibility and validation

Targets remain `net8.0`, `net9.0`, and `net10.0` on Windows, Linux, and
macOS. Production dependencies remain `Icod.TermInfo 1.17.0` and
`Icod.Timing 1.0.0`. The public API remains the 1.25 fingerprint
`886a617d961af7eed37feaed026d83bbf06ec508ba248a4ca492baaf7e528146`;
no consumer migration is required.

The release's qualification infrastructure is validated by fresh-package,
headless execution on all three target frameworks as well as the cross-platform
runtime, source-integration, package, API, matrix, and artifact gates.
Interactive evidence remains maintainer-reviewed rather than fabricated by CI.

Graphics qualification remains on hold and is outside this release's matrix.
