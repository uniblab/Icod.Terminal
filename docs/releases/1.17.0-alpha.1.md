# Icod.Terminal 1.17.0-alpha.1

## Terminal-owned screen contracts

This development release prepares the Terminal side of the future `Icod.DCurses`/`Icod.TermInfo` decoupling. DCurses can consume semantic dimensions, terminal-profile facts, safe terminal-operation plans, and one serialized screen-output transaction through `Icod.Terminal`; TermInfo remains an internal Terminal dependency.

Highlights:

- adds positive `TerminalDimensions`, `GetDimensions()`, and lifecycle dimension projections while preserving the existing TermInfo-based size APIs;
- adds immutable `TerminalProfile` and `TerminalScreenCapabilities` with colors, attributes, ACS, cursor visibility, and cursor-addressing facts;
- adds TermInfo-free semantic colors, rendition, line glyphs, cursor positions, erases, shifts, scrolling, alerts, and opaque costed plans;
- adds side-effect-free planning for cursor motion, rendition normalization/transitions, ACS glyphs, editing, scrolling, and scroll regions;
- adds a bounded single-use session-bound transaction for plans, application text, strict hyperlinks, raster-placeholder cells, synchronized framing, final flush, and stale-output rejection;
- qualifies the candidate package with two distinct downstream witnesses: published stable `Icod.DCurses 1.6.0`, plus a future-renderer consumer whose only direct package dependency is `Icod.Terminal` and whose source uses no TermInfo contracts;
- preserves caller ownership of retained cells, layout, Unicode width, clipping, damage, screen comparison, and repaint policy.
