# Icod.Terminal 1.27.0 Release Notes

**Status:** Stable `1.27.0` is prepared for maintainer review after selected live acceptance and all ten exact-head CI jobs passed. Merge, tag, GitHub release, and NuGet publication remain separate maintainer actions; this document does not claim publication.

## Terminal appearance and resize awareness

`TerminalSession.QueryAppearanceAsync` performs a bounded one-shot query and returns a typed dark or light observation without enabling reporting. Silence and endpoint limitations remain exceptional query outcomes; unknown values are not substituted for successful observations.

`AcquireAppearanceReportingAsync` and `AcquireInBandResizeReportingAsync` establish independently owned reporting leases after observing each private-mode baseline. Explicit unavailable states return `TerminalControlResult<T>.Unavailable`; malformed replies, cancellation, endpoint failure, and timeout retain their exceptional meaning. Opening a session enables neither reporting mode.

Valid unsolicited reports become typed semantic events on the existing authoritative input path. Active queries own matching responses first. Repeated appearance reports and repeated or pixel-only resize reports remain observations rather than cached state. Unknown pixel dimensions remain unknown. In-band dimensions do not replace native resize lifecycle events, `GetSize()`, or `GetDimensions()`.

Nested owners share their facility's reporting state. Final release restores only a fresh observed reset baseline; already-enabled modes remain enabled. Suspend/resume, external resume, invalidation, partial re-entry rollback, cancellation, EOF, and disposal participate in the existing restoration ordering. Applications continue to own theme selection, layout, damage, and repaint policy.

## Compatibility and distribution

Targets remain `net8.0`, `net9.0`, and `net10.0`, with managed Windows, Linux, and macOS support. Existing 1.x public members and enum values are preserved. The additive [1.27 API baseline](../Public-API-Baseline-1.27.md) is frozen at SHA-256 `356f455ec27065c63a642ae3d5b02125d2aed408d728cb6fadd0d47aeab12487` across all three frameworks.

Production dependencies remain `Icod.TermInfo 1.17.0` and `Icod.Timing 1.0.0`; no TermInfo change or consumer migration is required. The [stable 1.x policy](../Compatibility-and-Versioning.md) and existing [migration guide](../Migration-to-1.0.md) remain applicable.

The public-only compatibility sample adds consented bounded scenarios and cmd/sh launchers. Text checkouts use LF across Windows and WSL Git clients; reviewed JSON retains its original bytes. A clean Linux worktree avoids shared-checkout line-ending and Git-index inconsistencies without requiring SSH keys in WSL. Pressing `y` accepts live consent immediately; Enter selects No.

**Graphics development remains on hold.** This release makes no new raster support claim, Kitty graphics workaround, or persistent-ATLAS qualification. See [the hold record](../Graphics-Development-Hold.md).
