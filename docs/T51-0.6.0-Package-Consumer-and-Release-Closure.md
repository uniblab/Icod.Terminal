---

## 1. Purpose

T51 closes the `0.6.0` development line after T44–T50 froze, implemented,
audited, documented, and sampled the semantic OSC 8 hyperlink contract.

This tranche does not add a new terminal protocol or widen the reviewed public
API. It promotes the accepted `0.6.0-alpha.9` surface to stable `0.6.0` metadata
and extends package validation so the OSC 8 public API is compiled and executed
from the produced NuGet package itself on every supported target framework.

## 3. Frozen stable 0.6 public contract

The authoritative public API review is:

- [`Public-API-Baseline-0.6.md`](Public-API-Baseline-0.6.md)

The stable 0.6 delta remains exactly:

```csharp
public sealed class TerminalHyperlinkLease : IAsyncDisposable {
    public string Uri { get; }
    public string? Identifier { get; }
    public ValueTask DisposeAsync();
}

public ValueTask<TerminalHyperlinkLease> AcquireHyperlinkAsync(
    string uri,
    string? identifier = null,
    CancellationToken cancellationToken = default
);

public ValueTask WriteHyperlinkAsync(
    string value,
    string uri,
    string? identifier = null,
    CancellationToken cancellationToken = default
);
```

No raw OSC selector API, generic parameter dictionary, `System.Uri` normalization
overload, URI activation API, automatic linkification, or OSC 52 surface is added
during release closure.

## 4. Package-only OSC 8 consumer

T51 adds a dedicated package consumer under:

```text
tools/package-hyperlink-smoke/
```

The project references `Icod.Terminal` only through a NuGet `PackageReference`
whose version is injected by package verification. It has no project reference
to the repository library.

The package smoke exercises:

- bounded `WriteHyperlinkAsync(...)` output;
- percent-escape normalization in a hyperlink URI;
- explicit `id` emission;
- `TerminalHyperlinkLease.Uri` and `.Identifier` public properties;
- outer scoped hyperlink output;
- nested inner hyperlink acquisition;
- inner release restoring the outer OSC 8 state;
- final outer release emitting the canonical close frame;
- exact complete byte output;
- no implicit flush.

This proves the packaged public API is sufficient for both ordinary bounded use
and the stable scoped ownership model.

## 5. Multi-target fresh-consumer gate

`packaging/VerifyPackageArtifact.ps1` now creates four isolated package-only
consumer trees:

1. the general package smoke;
2. the 0.4 OSC title smoke;
3. the 0.5 OSC 7 location smoke;
4. the 0.6 OSC 8 hyperlink smoke.

All four restore from a temporary NuGet configuration whose first source is the
fresh artifact directory. NuGet.org remains available only for transitive
dependencies.

Each consumer executes against:

```text
net8.0
net9.0
net10.0
```

The isolated `NUGET_PACKAGES` directory prevents accidental reuse of an installed
`Icod.Terminal` package from the host machine.
