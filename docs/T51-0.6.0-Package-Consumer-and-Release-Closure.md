## 1. Purpose

T51 closes the `0.6.0` development line after T44–T50 froze, implemented,
audited, documented, and sampled the semantic OSC 8 hyperlink contract.

This tranche does not add a new terminal protocol or widen the reviewed public
API. It promotes the accepted `0.6.0-alpha.9` surface to stable `0.6.0` metadata
and extends package validation so the OSC 8 public API is compiled and executed
from the produced NuGet package itself on every supported target framework.

A final pre-release audit after the first green stable candidate identified one
lifecycle ownership gap: active OSC 8 state also had to participate in the same
suspend/resume neutralization and re-entry model already used by Terminal's other
reversible state. T51A closes that gap without changing the public API.

## 4. Final T51A lifecycle hardening

The final release audit requires OSC 8 to obey `TerminalSession` lifecycle ownership.

When a catchable suspend occurs with active hyperlink scopes:

1. higher-layer lifecycle participants prepare first;
2. the internal hyperlink manager emits one canonical OSC 8 close;
3. logical hyperlink lease ownership remains intact;
4. Terminal continues restoring rich-input, presentation, output, and host baseline state;
5. after successful host/session re-entry, the innermost active hyperlink begin frame is re-emitted;
6. higher-layer participants then resume.

For a nested stack `A/B`, the physical sequence across suspend/resume is therefore:

```text
... begin A
... begin B
OSC 8 close        # before suspension
OSC 8 begin B      # after successful re-entry
```

A subsequent release of `B` restores `A` normally.

An external resume notification without a caught suspend also re-emits the
innermost active hyperlink because physical terminal state is no longer assumed
to be trustworthy.

Failure semantics:

- failed suspend close participates in lifecycle failure handling;
- failed hyperlink re-entry prevents `TerminalSession.IsStateValid` from becoming
  true;
- logical ownership remains available for final cleanup;
- session disposal remains authoritative.

This hardening adds no public member and does not alter URI, parameter, nesting,
or package contracts.

```text

```

The project references `Icod.Terminal` only through a NuGet `PackageReference`
whose version is injected by package verification. It has no project reference
to the repository library.

The package smoke exercises:

- bounded `WriteHyperlinkAsync(...)` output;
- percent-escape normalization in a hyperlink URI;
- explicit `id` emission;
- `TerminalHyperlinkLease.Uri` and `.Identifier` public properties;
- outer scoped hyperlink output;
- nested inner hyperlink acquisition;
- inner release restoring the outer OSC 8 state;
- final outer release emitting the canonical close frame;
- exact complete byte output;
- no implicit flush.

This proves the packaged public API is sufficient for both ordinary bounded use
and the stable scoped ownership model.

## 10. T51A regression evidence required

The final source-test matrix now explicitly covers:

- single active hyperlink close-before-suspend and begin-after-resume;
- nested active scopes resuming the innermost state;
- inner release after resume restoring the outer state;
- suspend with no active OSC 8 state producing no hyperlink frame;
- repeated suspend/resume cycles producing one close/begin pair per cycle;
- external resume re-emitting active hyperlink state;
- failed hyperlink re-entry leaving session state invalid;
- bounded hyperlink output inside an outer scoped hyperlink restoring that outer
  state afterward.

These tests use injected lifecycle and output services; they do not depend on the
CI runner's terminal emulator.
