## Security and compatibility conclusions

The 1.5 normalization preserves these release invariants:

1. Existing wire-specific public methods keep their released bytes and semantics.
2. Terminal identity or vendor branding is not treated as capability proof.
3. Query timeout is not converted into unsupported truth.
4. Static TermInfo/profile evidence is separated from generation-scoped live evidence.
5. Explicit out-of-band state invalidation expires live capability conclusions.
6. One `TerminalSession` remains the sole authoritative input reader for its terminal conversation.
7. No generic raw CSI/DCS/OSC/APC/PM/SOS writer is introduced publicly.
8. Sixel remains a future DCS dialect and Kitty Graphics remains a future APC dialect; neither is prematurely exposed by 1.5.
