# Icod.Terminal 1.24.0 Raster Geometry and Planning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Do not use subagents for Icod.Terminal work.

**Goal:** Add public pixel and resource geometry, bounded local raster planning, generation-scoped frame-operation evidence, and a measured tile-atlas witness without transferring DCurses or game responsibilities into Terminal.

**Architecture:** Promote the existing internal CSI pixel-query and exact-derivation machinery into a small semantic public surface. Project immutable resource dimensions and synchronized local registry counts without new terminal I/O, and extend the existing generation-scoped evidence ledger with focused semantic raster operations rather than protocol ids or broad capability inflation. Exercise the completed contract through the existing raster-animation sample and fresh-package harness.

**Tech Stack:** C# 13; .NET 8/9/10; xUnit; PowerShell 5.1-compatible package verification; existing Terminal query manager, persistent-raster registries, evidence ledger, samples, and GitHub Actions matrix.

**Spec:** `docs/superpowers/specs/2026-10-02-1.24.0-raster-geometry-planning-design.md`

## Global Constraints

- Preserve the stable 1.0.0 compatibility floor and every existing public signature and enum numeric value.
- Production dependencies remain `Icod.TermInfo 1.17.0` and `Icod.Timing 1.0.0`; `Icod.TermInfo.Inspection` remains outside production.
- Preserve `net8.0`, `net9.0`, and `net10.0` with identical public API snapshots.
- Use the existing authoritative input/query coordinator; add no second reader, hidden query, cache, retry, replay, or terminal-brand branch.
- Keep tile maps, viewports, clipping, damage, frame-selection policy, asset processing, and game rules outside Terminal.
- Public geometry and planning remain semantic and backend-neutral; expose no CSI numbers, Kitty ids, registry objects, or evidence ledger.
- A planning snapshot reports library ceilings and advisory local counts, never authenticated remote capacity or a reservation.
- Operation-specific support becomes verified only after a matching acknowledged success in the current live generation.
- Version 1.24 adds no batch edits, Indexed8 partial updates, remote atomicity, rollback, absolute placement, or pixel-within-cell positioning.
- Implement inline through `superpowers:executing-plans`; the user has requested no subagents for Icod.Terminal work.

## Review Focus

- A late CSI 16 t reply after timeout must remain owned by the expired query and cannot satisfy a later CSI 14 t query; Task 2 adds the regression.
- Concurrent frame append reservation must count against `MaximumAnimationFrames` even before acknowledgement; Task 4 adds the regression.
- One successful RGB24 update must not verify RGBA32 update or frame composition; Task 5 adds the regression.
- Resource geometry must remain readable after disposal without implying current remote ownership; Task 3 adds the regression.
- A lifecycle-generation advance racing with acknowledgement must not publish new-generation operation evidence; Task 6 adds the regression.
