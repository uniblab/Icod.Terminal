# Icod.Terminal 1.28.0 Published-Spec Kitty Graphics Transactions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. The maintainer selected inline execution in the main session without subagents.

**Goal:** Make persistent Kitty Graphics animation mutations conform to the published protocol, expose the actual confirmation strength of successful mutations, and provide the dependable Terminal primitives needed to qualify the downstream Icod.DCurses compose-publish atlas.

**Architecture:** Keep the existing protocol-private encoder, one authoritative input/query reader, query ambiguity ownership, shared control-output gate, generation-scoped persistent-resource ownership, and opaque frame tokens. Add an exhaustive private response policy, replace append-only commitment tracking with operation-neutral emission state, retain required replies for `a=f`, make `a=a` output-only with `q=2`, and classify `a=c` silence after complete write/flush as output commitment rather than acknowledgement.

**Tech Stack:** C# 13; .NET 8, 9, and 10; xUnit; PowerShell 5.1-compatible packaging; cmd/sh launchers; Kitty Graphics Protocol; GitHub Actions on Windows, Linux, and macOS.

**Spec:** [`../specs/2026-10-06-1.28.0-published-spec-kitty-graphics-transactions-design.md`](../specs/2026-10-06-1.28.0-published-spec-kitty-graphics-transactions-design.md)

**Roadmap:** [`../../../Icod.Terminal-1.28.0-Development-Roadmap.md`](../../../Icod.Terminal-1.28.0-Development-Roadmap.md), tranches T2800-T2810.

**Execution selection:** After maintainer approval of this plan, execute inline in the main session without subagents. Use strict RED -> GREEN -> REFACTOR cycles and stop on a design contradiction rather than silently changing the approved contract.

## Global Constraints

- Preserve the stable `1.0.0` compatibility floor and every existing public enum value.
- Preserve `net8.0`, `net9.0`, and `net10.0`; C# 13; `Icod.TermInfo 1.17.0`; and `Icod.Timing 1.0.0` unless a separate dependency decision is approved.
- Add no terminal-name, process-name, version-string, `TERM`, environment-variable, or implementation-profile branch.
- Encode the published continuation grammar: later `a=f` chunks contain `a=f,m=1` or `a=f,m=0` and never repeat `i` as a Kitty 0.49.2 workaround.
- Preserve one authoritative input/query reader, the existing ambiguity gate, bounded late-response ownership, and the existing shared control-output gate.
- Register required/optional response ownership before output; never hold the control-output gate while awaiting a response.
- Revalidate session, generation, resource, animation, sequence, and frame ownership under the output gate immediately before the first byte.
- Once emission starts, do not use caller cancellation to truncate an APC frame; propagate write and flush failures without reporting success.
- Record `TerminalCapabilityEvidenceSource.ProtocolResponse` only after a correlated current-generation reply is parsed.
- Keep image ids, frame numbers, quiet values, response policy, implementation identity, and raw protocol operations private.
- Add no public atlas/batch/scene API, replay cache, pixel-certainty type, retry, backend switch, PTY/ConPTY host, image decoder, or Terminal-owned cell/damage/layout policy.
- Keep automated, source-based, package-consumer, and operator-visible evidence distinct. `Committed`, `acknowledged`, and `rendered` are not synonyms.
- Use .NET/C#, PowerShell 5.1, cmd, and sh only. Do not add Python tooling.
- Run every task at the exact branch head it claims. Do not set stable 1.28 metadata, tag, publish, or merge until live and package acceptance is complete.

## Review Focus

1. A timeout can race the first write or final flush. Tasks 2, 3, and 5 must prove `HasStarted` after the first complete APC write and `OutputCommitted` only after every frame plus final flush.
2. An `a=a` control can wait behind disposal or generation invalidation. Task 4 must prove revalidation under the output gate returns `Unavailable` and emits zero bytes.
3. A late composition APC can arrive after optional-response timeout. Tasks 5 and 6 must prove it remains owned/quarantined, cannot complete a later transaction, and cannot create current-generation evidence.
4. Unsolicited, malformed, wrong-id, placement, and image-number APC traffic can interleave with output-only controls and ordinary input. Tasks 4-6 must prove no response theft, no extra reader, and ordinary input preservation.
5. Public compatibility is additive only. Tasks 1 and 8 must prove `Success()` remains `Unspecified`, `Succeeded` remains status-based, existing animation signatures stay unchanged, enum values are stable, and all framework snapshots match.

## Frozen Interfaces

The following shapes are implementation authority for this plan:

```csharp
public enum TerminalControlMutationConfirmation {
    Unspecified = 0,
    OutputCommitted = 1,
    ProtocolAcknowledged = 2
}

public sealed class TerminalControlMutationResult {
    public TerminalControlMutationConfirmation Confirmation { get; }
    public bool Succeeded { get; }
    public static TerminalControlMutationResult Success();
    internal static TerminalControlMutationResult Success(
        TerminalControlMutationConfirmation confirmation
    );
}

internal enum KittyGraphicsPersistentAnimationResponsePolicy {
    None,
    Optional,
    Required
}
```

`TerminalControlMutationResult.Success()` returns `Unspecified`. Controlled unavailable, unsupported, and failed results also return `Unspecified`. `AddFrameAsync` keeps returning `TerminalControlResult<TerminalRasterAnimationFrame>`; publishing a frame token remains proof of a required acknowledged transfer.

The private policy mapper must explicitly map full/partial frame transfer to `Required`, animation control to `None`, and composition to `Optional`; an unknown operation value throws rather than inheriting a default.
