# Icod.Terminal 1.17.0 Terminal Screen Output Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the additive Terminal-owned dimensions, semantic profile/planner, and session-bound screen-output transaction needed for a TermInfo-free DCurses 2.0 boundary.

**Architecture:** Terminal projects its selected TermInfo description into immutable semantic contracts, creates opaque operation plans, and commits bounded typed output batches under its existing output gate. DCurses remains responsible for retained-screen state and refresh policy.

**Tech Stack:** C# 13, .NET 8/9/10, xUnit, PowerShell 5.1 packaging scripts, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-17-1.17.0-terminal-screen-output-design.md`

## Global Constraints

- Preserve the stable `1.0.0` compatibility floor and existing 1.x signatures.
- Keep `Icod.TermInfo` as the production capability-data authority without exposing it through new screen APIs.
- Keep cells, layout, damage, Unicode width, and refresh strategy outside Terminal.
- Use C#, PowerShell 5.1, and repository cmd/sh tooling only.
- Target `net8.0`, `net9.0`, and `net10.0` on Windows, Linux, and macOS.
- Follow strict TDD: each production behavior starts with a failing test.
