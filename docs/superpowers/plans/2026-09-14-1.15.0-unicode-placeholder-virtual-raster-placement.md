# Unicode Placeholder and Virtual Raster Placement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add backend-neutral virtual raster placeholders and self-contained Unicode placeholder-cell rendering to `Icod.Terminal 1.15.0` without exposing Kitty protocol identity or moving screen-layout ownership into Terminal.

**Architecture:** Extend the existing persistent-raster ownership domain with an opaque virtual-placement state/handle and immutable semantic cell token. Reuse the existing authoritative Kitty persistent placement transaction, registry, 1.14 lifecycle state, output gate, and relative-placement graph; keep Unicode/SGR encoding in a dedicated internal encoder and make every rendered cell self-contained.

**Tech Stack:** C# 13; .NET `net8.0`, `net9.0`, `net10.0`; xUnit; PowerShell package verification; Kitty Graphics Protocol; existing Icod.Terminal persistent-raster/query/output infrastructure.

**Spec:** `docs/superpowers/specs/2026-09-14-1.15.0-unicode-placeholder-virtual-raster-placement-design.md`

## Global Constraints

- Stable compatibility floor remains `1.0.0`.
- Preserve all released `TerminalCapability` numeric values; candidate `UnicodeRasterPlaceholders` is additive value `10`.
- Preserve target frameworks `net8.0;net9.0;net10.0` and C# 13.
- Placeholder `Columns` and `Rows` are both required and bounded to `1..256`.
- Session ceilings remain 256 resources, 4096 combined physical/virtual placements, relative depth 8.
- Virtual-placement ids are private, nonzero, collision-safe, wrap-safe, and restricted to `1..0x00FFFFFF`.
- No public Kitty image/placement ids, session generation ids, `U+10EEEE`, combining-table values, raw APC commands, or backend selector.
- Every placeholder cell is independently renderable; no left-neighbor shorthand.
- Placeholder cell output is current-cursor text output. Terminal does not own screen coordinates, windows, clipping, scrolling, damage, or layout.
- Reuse `TerminalRasterOwnershipState`; do not introduce a second lifecycle enum family.
- No hidden source-raster cache, replay/re-upload, Sixel placeholder emulation, animation, absolute placement, image decoding, or PTY/ConPTY hosting.
- Production dependencies remain centralized in `Icod.Terminal.csproj`; do not add a production dependency solely for 1.15.
