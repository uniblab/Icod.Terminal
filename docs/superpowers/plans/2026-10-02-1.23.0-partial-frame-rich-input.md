# Icod.Terminal 1.23.0 Partial Frame and Rich Input Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add bounded caller-supplied partial animation-frame updates, complete the approved rich-input gaps, and qualify the release through samples and fresh-package consumers.

**Architecture:** Partial transfer is a resource-owned `TerminalRasterAnimation` mutation that reuses the 1.22 output gate, response correlation, frame ownership, and ambiguous-commit rules. Rich input remains in the existing decoder, protocol-lease, response-routing, and authoritative event-reader architecture. Samples and package witnesses exercise semantic public contracts without raw protocol identities.

**Tech Stack:** C# 13; .NET 8, 9, and 10; existing Kitty graphics transaction path; existing input framing and protocol leases; PowerShell 5.1-compatible package verification.

**Spec:** `docs/superpowers/specs/2026-10-02-1.23.0-partial-frame-rich-input-design.md`

## Global Constraints

- Preserve the stable `1.0.0` compatibility floor and all existing public enum values.
- Preserve one authoritative input/query/event reader per live session.
- Keep frame identities opaque, generation-scoped, and bounded; never add hidden source or delta replay caches.
- Keep cells, windows, layout, clipping, damage, keymaps, and editing policy in callers.
- Keep PTY/ConPTY hosting, image codecs, raw protocol dispatch, and Inspection outside the production dependency graph.
- Support `net8.0`, `net9.0`, and `net10.0` with equal normalized public API snapshots.
- Treat committed timeout, cancellation, transport failure, and ambiguous input ownership conservatively; never blindly replay emitted mutations.

## Review Focus

- A partial update that emits successfully but loses its acknowledgement must leave affected pixels uncertain while retaining only known frame identity. Test in Task 4.
- A partial update queued behind playback or disposal must recheck ownership at the output gate. Test in Task 4.
- A caller-supplied region with unsupported format, overflowed coordinates, or a zero extent must fail before bytes. Test in Task 2.
- Malformed or oversized input must recover at the next semantic boundary without poisoning later events. Test in Task 6.
- Protocol leases and associated text/paste/mouse payloads must not leak state or silently widen privacy exposure. Test in Task 6.
