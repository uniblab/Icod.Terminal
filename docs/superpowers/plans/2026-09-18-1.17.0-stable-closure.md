# Icod.Terminal 1.17.0 Stable Closure Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Promote the already-qualified `1.17.0-alpha.1` implementation to a fully documented, reproducible, exact-head `1.17.0` stable candidate without merging, tagging, releasing, or publishing it.

**Architecture:** T179 is a release-authority and evidence closure, not a production-code tranche. One candidate commit changes only version/package metadata and permanent documentation, then the existing runtime, package, API/XML, stable-consumer, and downstream DCurses gates qualify that exact tree. A later evidence-only bookkeeping commit records the accepted workflow and is independently requalified so the documented head is also the final green head.

**Tech Stack:** C# 13, .NET 8/9/10, xUnit, PowerShell 5.1-compatible packaging scripts, GitHub Actions, NuGet package-only consumers.

**Design authority:** `Icod.Terminal-1.17.0-Development-Roadmap.md`, `docs/superpowers/specs/2026-09-17-1.17.0-terminal-screen-output-design.md`, and `docs/superpowers/plans/2026-09-17-1.17.0-terminal-screen-output.md`.

## Global constraints

- Preserve every released Terminal 1.x signature and the frozen 1.17 API fingerprint.
- Make no production-code or behavioral change during T179.
- Keep `Icod.TermInfo` and `Icod.Timing` dependency identities unchanged.
- Keep `docs/releases/1.17.0-alpha.1.md` as historical prerelease documentation.
- Do not claim that `1.17.0` is published before publication.
- Do not merge PR #61, create tag `v1.17.0`, create a GitHub Release, or publish packages without explicit maintainer authorization.
- Use only repository-supported C#/.NET, PowerShell 5.1, cmd, and sh tooling; do not use Python.
