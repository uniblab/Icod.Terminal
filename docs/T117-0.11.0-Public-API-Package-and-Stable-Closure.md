# T117 — 0.11.0 Public API, Package, and Stable Closure

**Release:** `0.11.0`  
**Tranche:** `T117`  
**Current development version:** `0.11.0-alpha.7`  
**Status:** Stable-closure preparation complete; cumulative and stable exact-head validation required

---

## 1. Purpose

T117 closes the OSC 22 terminal mouse-pointer release without expanding its reviewed public surface.

No new protocol family or public API is introduced after T116.

---

## 2. Frozen public delta

The reviewed 0.11 delta is recorded in `docs/Public-API-Baseline-0.11.md` and is limited to:

- `TerminalPointerShape` with exactly 30 semantic values;
- `TerminalPointerShapeLease` and `Shape`;
- `TerminalPointerShapeObservation` with `HasShape` and `Shape`;
- `TerminalSession.SetPointerShapeAsync(...)`;
- `TerminalSession.ResetPointerShapeAsync(...)`;
- `TerminalSession.AcquirePointerShapeAsync(...)`;
- `TerminalSession.QueryCurrentPointerShapeAsync(...)`;
- `TerminalSession.QueryDefaultPointerShapeAsync(...)`;
- `TerminalSession.QueryGrabbedPointerShapeAsync(...)`;
- `TerminalSession.QueryPointerShapeSupportAsync(...)`.

No raw OSC 22 API, arbitrary pointer-name string, Kitty push/pop API, automatic support flag, or terminal-emulator inference is added.

---

## 3. Source sample closure

T117 adds `samples/Icod.Terminal.PointerShape.Sample` as a normal `Icod.Terminal.sln` project.

The sample demonstrates:

- explicit semantic pointer set and terminal-policy reset;
- nested `Pointer` / `Wait` scoped ownership;
- restoration of the outer Icod-owned shape;
- final reset to terminal policy;
- explicit bounded pointer-support query;
- explicit current-pointer observation;
- timeout reported as unknown support rather than unsupported.

The sample intentionally does not perform emulator detection or claim observed support from successful output alone.

---

## 4. Package-only consumer closure

T117 adds:

- `tools/package-pointer-shape-smoke/Icod.Terminal.PackagePointerShapeSmoke.csproj`;
- `tools/package-pointer-shape-smoke/Program.cs`;
- `packaging/VerifyPointerShapePackage.ps1`.

The fresh package consumer is copied outside the repository project-reference graph and restored only against the newly produced `Icod.Terminal` package plus normal NuGet dependencies.

It validates on net8.0, net9.0, and net10.0:

- CSS `default` semantic set versus empty OSC 22 terminal-policy reset;
- nested `Pointer`, `Text`, and `Wait` owners;
- out-of-order non-controlling disposal is silent;
- controlling disposal restores the newest remaining owner;
- final release emits terminal-policy reset;
- repeated successful disposal is idempotent;
- pointer-shape operations do not implicitly flush;
- all four public pointer query method signatures are available from the packaged assembly.

## 5. XML documentation gate

The fresh package must contain generated XML documentation for every supported TFM and include:

- the `TerminalPointerShape` type;
- all 30 public enum members;
- `TerminalPointerShapeLease`, `Shape`, and `DisposeAsync()`;
- `TerminalPointerShapeObservation`, `HasShape`, and `Shape`;
- every new 0.11 `TerminalSession` pointer method.

Missing documentation is a release-blocking package failure.

T117 also completes public query documentation for timeout, cancellation, malformed response, endpoint requirements, and no-shape semantics.
