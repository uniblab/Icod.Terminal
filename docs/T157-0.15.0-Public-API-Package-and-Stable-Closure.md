# T157 — 0.15.0 Public API, Package, and Stable Closure

**Release:** `Icod.Terminal 0.15.0`  
**Tranche:** T157  
**Version:** `0.15.0`  
**Theme:** stable closure of typed OSC 133 extended semantic metadata

## Delivered

T157 closes the 0.15 release without adding protocol or runtime behavior.

### Stable public baseline

`docs/Public-API-Baseline-0.15.md` freezes:

- the three prompt metadata enums;
- `TerminalSemanticPromptOptions`;
- `TerminalSemanticCommandOutputOptions`;
- the two new `TerminalSession` overloads;
- portable 0.12 `A/B/C/D` byte compatibility;
- canonical prompt parameter ordering;
- strict UTF-8 / uppercase `%HH` `cmdline_url` encoding;
- the 65,536-byte encoded OSC 133 payload ceiling;
- lifecycle, ordering, failure, and privacy semantics;
- explicit exclusions including shell `%q` `cmdline=` and automatic command capture/redaction.

### User-facing documentation and sample

The root README now leads with 0.15 OSC 133 extended metadata, documents interoperability tiers, demonstrates typed prompt and command-output metadata, and includes the command-line privacy warning.

`Icod.Terminal.SemanticPrompt.Sample` retains the portable sequence and adds typed prompt metadata plus explicit `cmdline_url` publication guidance.

### Fresh NuGet-only package contract

T157 adds:

- `tools/package-semantic-metadata-smoke/`;
- `packaging/VerifySemanticMetadataPackage.ps1`.

The verifier opens the freshly produced package, checks XML documentation for every new 0.15 public type/member/overload on net8/net9/net10, then restores and runs a fresh consumer that references only the packed `Icod.Terminal` NuGet artifact.

The historical 0.8–0.14 package verifiers remain unchanged and retained.

### Validation wiring

The new 0.15 package verifier is part of:

- pull-request Staging package validation;
- `VerifyDistribution.ps1`, which is used by exact-main Release validation;
- tagged Release package validation before publication.

Real downstream `Icod.DCurses` semantic-prompt acceptance remains part of PR, distribution/main, and tagged release validation and now includes the T156 extended sequence.

### Stable metadata

The prerelease suffix is removed:

```text
VersionPrefix:    0.15.0
VersionSuffix:
Version:          0.15.0
PackageVersion:   0.15.0
AssemblyVersion:  0.15.0.0
TargetFrameworks: net8.0;net9.0;net10.0
```

Package release notes/tags are updated for the 0.15 OSC 133 metadata contract.

## Release gate

The authoritative stable PR head must be green before merge.

After merge, the exact resulting `main` commit must pass the six-platform Release/distribution matrix before tag `v0.15.0` is created.

The tagged release workflow must then re-run build/tests, downstream acceptance, exact package selection, retained 0.8–0.14 package contracts, and the new 0.15 semantic-metadata package contract before NuGet.org/GitHub Packages publication.

## Conclusion

T157 completes the planned 0.15 development roadmap. No additional feature/API work is part of this tranche.
