## 5. README and sample closure

The root README now presents lifecycle-safe scoped ownership as the primary safe mutation/restoration path.

It explicitly documents that:

- first acquisition observes the external baseline before mutation;
- final release replays the observed value;
- OSC 104 and OSC 110–119 are terminal-policy resets, not restoration;
- unscoped set/reset is rejected while scoped ownership is active;
- managed suspend restores external baselines;
- resume establishes fresh baselines before reapplying retained ownership;
- session disposal is the final cleanup owner;
- a higher-level owner such as `Icod.DCurses` triggers Terminal-owned color restoration when it disposes a supplied `TerminalSession` it owns.

`Icod.Terminal.Color.Sample` retains its observation-first default mode and changes `--mutate` to demonstrate `TerminalPaletteColorLease` and `TerminalDynamicColorLease` rather than set/reset pseudo-restoration.
