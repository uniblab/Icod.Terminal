## D179 hardening evidence

D179 retains the D170–D178 unit and integration coverage and adds release-oriented witnesses for the completed public raster path.

### Low-compressibility maximum-width Sixel

A maximum-width (`16,384`) alternating two-color row deliberately defeats useful Sixel RLE. The regression requires a near-full-width color-pass segment while asserting that every produced segment remains bounded by the documented width-derived ceiling. This complements the existing maximum-width highly-compressible RLE case.

The purpose is to prove that segmentation remains bounded for both favorable and unfavorable input patterns rather than merely demonstrating compression on uniform images.

### Fresh NuGet-only raster consumer

`packaging/VerifyRasterGraphicsPackage.ps1` is part of the semantic package shard. For the freshly packed `Icod.Terminal` artifact it:

- verifies generated XML documentation for `TerminalRasterPixelFormat`, `TerminalRasterColor`, `TerminalRasterImage`, their reviewed public members, and `TerminalSession.DisplayRasterAsync(...)` on `net8.0`, `net9.0`, and `net10.0`;
- restores a temporary consumer against the freshly packed local NuGet artifact;
- compiles and runs that consumer independently on all three TFMs;
- binds the public semantic display method without using repository project references;
- constructs RGB24, RGBA32, and Indexed8 images from the package;
- verifies raster snapshot/value semantics;
- verifies the frozen public pixel-format enum numbers;
- verifies that raw DCS/Sixel writers and direct raster backing-memory access have not leaked into the public API.

The verifier is invoked by the semantic package-contract shard and therefore runs in PR, main, distribution, and release package validation.

## Retained safety and compatibility boundaries

Version 1.7 retains these permanent constraints:

- one authoritative `TerminalSession` input reader;
- terminal/query responses are untrusted external input;
- terminal brand, `TERM`, host OS, and caller preference are not protocol capability proof;
- Primary DA attribute `4` may verify Sixel support, while absence or timeout does not manufacture `Unsupported` evidence;
- raster dimensions, pixel count, owned storage, palette size, quantizer work state, DCS small-frame size, and streaming segments are bounded;
- large Sixel output does not allocate one complete encoded frame;
- caller cancellation is honored before a Sixel transaction commits but cannot truncate a committed DCS string;
- committed Sixel output holds the existing session output serialization gate through final ST and flush;
- transport failure after commitment is surfaced without automatic retry or speculative terminator recovery;
- session teardown drains committed output before restoration proceeds;
- no generic public DCS/Sixel writer or explicit Sixel backend selector is introduced;
- image-file decoding, placement/scaling policy, animation, persistent image identifiers, and Kitty Graphics remain outside 1.7.
