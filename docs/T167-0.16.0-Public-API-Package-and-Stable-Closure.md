# T167 — 0.16.0 Public API, Package, and Stable Closure

**Release:** `Icod.Terminal 0.16.0`  
**Tranche:** T167  
**Version:** `0.16.0`  
**Theme:** stable closure of bounded safe OSC 9 semantic extensions

## Delivered

T167 closes the 0.16 release without adding new runtime protocol behavior beyond T160–T166.

### Stable public baseline

`docs/Public-API-Baseline-0.16.md` freezes the complete 0.16 public delta:

```csharp
ValueTask SendNotificationAsync(
	string message,
	CancellationToken cancellationToken = default
);

ValueTask PublishWindowsCurrentDirectoryCompatibilityAsync(
	string windowsPath,
	CancellationToken cancellationToken = default
);
```

The baseline also freezes strict UTF-8/control rejection, payload limits, ST framing, OSC 7 precedence, retained OSC 9;4 compatibility, lifecycle semantics, privacy guidance, and the hazardous/generic OSC 9 exclusion set.

### Documentation and sample closure

The root README now leads with the 0.16 safe OSC 9 contract and documents:

- notification semantics and privacy;
- explicit OSC 9;9 Windows CWD compatibility;
- why OSC 7 remains preferred;
- lifecycle/ordering behavior;
- hazardous vendor command exclusions.

`Icod.Terminal.Location.Sample` now supports an explicit `windows-osc9` mode while retaining all existing OSC 7 modes. It does not auto-detect terminal brand or publish OSC 9;9 implicitly.

### Fresh NuGet-only package contract

T167 adds:

- `tools/package-safe-osc9-smoke/`;
- `packaging/VerifySafeOsc9Package.ps1`.

The verifier opens the freshly produced package and checks XML documentation for both new public methods on net8/net9/net10, then restores and runs a fresh consumer that references only the packed `Icod.Terminal` NuGet artifact.

Historical 0.8–0.15 package verifiers remain unchanged and retained.

### Validation wiring

The 0.16 package verifier is now part of:

- pull-request Staging package validation;
- `VerifyDistribution.ps1`, which backs exact-main Release validation;
- tagged Release package validation before publication.

Real downstream `Icod.DCurses` acceptance remains part of PR, distribution/main, and tagged release validation and includes the T166 safe OSC 9 sequence.

### Stable metadata

The prerelease suffix is removed:

```text
VersionPrefix:    0.16.0
VersionSuffix:
Version:          0.16.0
PackageVersion:   0.16.0
AssemblyVersion:  0.16.0.0
TargetFrameworks: net8.0;net9.0;net10.0
```

Package release notes/tags are updated for notification and OSC 9;9 compatibility while explicitly retaining OSC 7 and OSC 9;4 contracts.

## Release gate

The exact stable PR head must be green before merge.

After merge, the exact resulting `main` commit must pass Release/distribution validation before tag `v0.16.0` is created.

The tagged release workflow must then rerun build/tests, downstream acceptance, exact package selection, retained 0.8–0.15 package contracts, and the new 0.16 safe OSC 9 package contract before NuGet.org/GitHub Packages publication.

## Conclusion

T167 completes the planned 0.16 roadmap. No additional feature/API work is part of this tranche.
