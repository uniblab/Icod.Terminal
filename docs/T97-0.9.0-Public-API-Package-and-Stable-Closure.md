## 1. Stable public delta

The 0.9 public API is frozen in `docs/Public-API-Baseline-0.9.md`.

New public surface:

```csharp
public sealed class TerminalSynchronizedOutputLease : IAsyncDisposable {
	public ValueTask DisposeAsync();
}

public ValueTask<TerminalSynchronizedOutputLease> AcquireSynchronizedOutputAsync(
	CancellationToken cancellationToken = default
);
```

No additional support flag, raw private-mode API, nesting-depth property, query surface, or application-side transaction buffer is introduced during closure.

The acquisition XML contract explicitly documents that synchronized output requires an interactive terminal output endpoint and that caller cancellation applies before logical ownership commits.

## 2. Focused source sample

`samples/Icod.Terminal.SynchronizedOutput.Sample` demonstrates:

- opening a normal interactive `TerminalSession`;
- acquiring one semantic synchronized-output lease;
- performing ordinary session writes inside that lease;
- preserving existing semantic output APIs such as window-title publication;
- automatic final mode-off and flush through lease disposal;
- truthful documentation that successful completion proves emission rather than terminal-side support.

The sample targets `net8.0`, `net9.0`, and `net10.0` and is a normal `Icod.Terminal.sln` project under the solution `samples` folder. Ordinary solution restore/build therefore validates it on every configured build path; no redundant sample-only build step is required.

## 3. Fresh NuGet-only package consumer

`tools/package-synchronized-output-smoke` references only the freshly produced `Icod.Terminal` package.

The consumer verifies:

1. first acquisition emits canonical `ESC[?2026h`;
2. nested acquisition emits no second begin frame;
3. non-final release emits no end frame and performs no flush;
4. ordinary session output remains legal inside the lease;
5. final release emits canonical `ESC[?2026l`;
6. final release contributes exactly one flush;
7. successful repeated disposal is idempotent.

The consumer runs under `net8.0`, `net9.0`, and `net10.0`.

## 6. Regression discovery during closure

T94 initially attempted to serialize the historical low-level `WriteTerminalStringAsync(...)` primitive by recursively acquiring the session output gate.

The regression suite exposed that change as a deadlock because presentation and input-protocol managers intentionally hold the control-output gate while invoking the low-level terminfo primitive.

The attempted redefinition was reverted before stable closure. The historical contract remains:

- session semantic managers serialize their transition batches through the shared control-output gate;
- direct external callers of raw `WriteTerminalStringAsync(...)` remain responsible for coordinating that advanced low-level output with concurrent session traffic.

The corrected cumulative branch passed workflow #347.

## 7. Final pre-merge hardening

The final audit added two focused regression invariants:

1. synchronized-output acquisition on a redirected/non-terminal output endpoint throws `InvalidOperationException` without emitting mode-2026 bytes or flushing;
2. when session disposal owns both presentation state and synchronized output, presentation restoration completes before the final `CSI ? 2026 l`, preserving synchronized-output release as the final presentation boundary.

The audit also moved the focused 0.9 sample into `Icod.Terminal.sln` and removed redundant sample-only build steps from PR, distribution, and tagged-release validation.
