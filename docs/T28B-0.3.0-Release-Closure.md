## 3. Stable 0.3 contract

Stable 0.3 includes:

- one bounded session-owned terminal input path;
- expectation-driven response interpretation;
- ambiguity-sensitive query serialization;
- ordinary `OperationCanceledException` caller cancellation;
- caller-visible `TimeoutException` deadlines;
- bounded internal late-response ownership after emitted requests;
- typed Primary and Secondary Device Attributes;
- standard Device Status Report;
- one-based Cursor Position Report;
- typed DECRQSS positive/negative status-string results;
- byte-preserving XTGETTCAP live capability observations;
- explicit probing with no automatic interrogation during session open;
- package-only validation for every public 0.3 query family;
- Windows, Ubuntu, and macOS validation for `net8.0`, `net9.0`, and `net10.0`.

No public aggregate probe object, raw response reader, caller-extensible response
matcher, or general protocol-registration API is introduced.

## 7. Final stable validation

After this patch is committed on a branch based on current `main`:

1. run the normal local clean/restore/build/test/pack sequence;
2. require the PR validation matrix to pass;
3. merge the stable release commit to `main`;
4. require the ordinary `main` Release validation to pass;
5. verify `main` contains the exact stable release commit;
6. create the annotated `v0.3.0` tag only then.

Do not manually publish the stable package from the development branch.

---

## 8. Publication

From a checkout whose `main` points at the validated stable release commit:

```text
git tag -a v0.3.0 -m "Icod.Terminal 0.3.0"
git push origin v0.3.0
```

The tag-controlled release workflow must:

- confirm that the tagged commit is contained in `main`;
- confirm tag/version/package-version agreement;
- rebuild and retest on Windows, Ubuntu, and macOS;
- regenerate and verify the Release package;
- publish `Icod.Terminal 0.3.0` to NuGet.org;
- publish the same package to GitHub Packages;
- create SHA-256 checksums;
- create the GitHub Release and attach the package, symbol package, and
  checksums.
