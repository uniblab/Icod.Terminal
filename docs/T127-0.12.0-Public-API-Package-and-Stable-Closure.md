## 1. Purpose

T127 closes the OSC 133 semantic-prompt release without expanding the reviewed public surface frozen in T120/T124.

No new protocol family or semantic operation is introduced after T126.

---

## 2. Frozen public delta

The stable 0.12 delta is recorded in `docs/Public-API-Baseline-0.12.md` and consists of exactly five `TerminalSession` methods:

```csharp
ValueTask BeginPromptAsync(
	CancellationToken cancellationToken = default
);

ValueTask BeginCommandInputAsync(
	CancellationToken cancellationToken = default
);

ValueTask BeginCommandOutputAsync(
	CancellationToken cancellationToken = default
);

ValueTask FinishCommandAsync(
	byte exitStatus,
	CancellationToken cancellationToken = default
);

ValueTask AbortCommandAsync(
	CancellationToken cancellationToken = default
);
```

No public raw marker enum, arbitrary OSC 133 payload API, nullable completion status, scoped command-region lease, or retained shell-history state is added.

---

## 3. Source sample closure

T127 adds `samples/Icod.Terminal.SemanticPrompt.Sample` as a normal `Icod.Terminal.sln` project.

The sample demonstrates:

- prompt start;
- command-input start;
- command-output start;
- explicit successful completion with exit status `0`;
- a second prompt/input region terminated by explicit abort;
- ordinary application text interleaved with semantic markers.

The sample does not perform emulator detection or claim OSC 133 support from successful output alone.

## 4. Package-only consumer closure

T127 adds:

- `tools/package-semantic-prompt-smoke/Icod.Terminal.PackageSemanticPromptSmoke.csproj`;
- `tools/package-semantic-prompt-smoke/Program.cs`;
- `packaging/VerifySemanticPromptPackage.ps1`.

The fresh consumer is copied outside the repository project-reference graph and restored from the newly packed `Icod.Terminal` artifact plus normal NuGet dependencies.

It validates on `net8.0`, `net9.0`, and `net10.0`:

- all five stable public method signatures are available from the packaged assembly;
- canonical A/B/C/D frames are emitted;
- `FinishCommandAsync(0)` remains distinct from `AbortCommandAsync()`;
- committed writes are non-caller-cancellable;
- marker methods do not implicitly flush.
