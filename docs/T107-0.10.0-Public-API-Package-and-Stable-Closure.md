# T107 — 0.10.0 Public API, Package, and Stable Closure

**Release:** `0.10.0`  
**Tranche:** `T107`  
**Current version:** `0.10.0`  
**Status:** Complete; merge requires exact stable-head green validation

---

## 1. Purpose

T107 closes the OSC 9;4 terminal-progress release without expanding its reviewed public surface.

No new protocol family or public API is introduced after T106.

---

## 2. Frozen public delta

The reviewed 0.10 delta is recorded in `docs/Public-API-Baseline-0.10.md` and is limited to:

- `TerminalProgressState`;
- `TerminalProgressLease`;
- two `ReportAsync(...)` overloads;
- `SetIndeterminateAsync(...)`;
- `TerminalProgressLease.DisposeAsync()`;
- `TerminalSession.AcquireProgressAsync(...)`.

No support flag, wire-state number, raw OSC 9 API, nesting-depth API, or progress query is added.

---

## 3. Source sample closure

T107 adds `samples/Icod.Terminal.Progress.Sample` as a normal `Icod.Terminal.sln` project.

The sample demonstrates:

- completed/total stage reporting;
- transition to indeterminate progress;
- the semantic attention state;
- automatic final clear through lease disposal.

The sample intentionally does not perform emulator detection or claim observed support.

---

## 4. Package-only consumer closure

T107 adds:

- `tools/package-progress-smoke/Icod.Terminal.PackageProgressSmoke.csproj`;
- `tools/package-progress-smoke/Program.cs`;
- `packaging/VerifyProgressPackage.ps1`.

The fresh package consumer is copied outside the repository project-reference graph and restored only against the newly produced `Icod.Terminal` package plus normal NuGet dependencies.

It validates on net8.0, net9.0, and net10.0:

- 1/10 -> 10 percent;
- 2/10 -> 20 percent;
- unreported nested owner does not mask outer progress;
- inner indeterminate state;
- logical-only outer attention update while inner controls;
- restoration to outer attention 7/10 on inner release;
- final clear;
- idempotent repeated successful disposal;
- no implicit progress flush.
